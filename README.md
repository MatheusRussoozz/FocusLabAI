
# 🎯 FocusLab AI

### Plataforma inteligente de estudos com Java, Spring Boot e Inteligência Artificial

O **FocusLab AI** é um projeto backend desenvolvido com o objetivo de criar uma API REST para gerenciamento de estudos, organização de conteúdos e geração de simulados personalizados utilizando Inteligência Artificial.

O projeto nasceu como uma evolução dos conhecimentos adquiridos durante o desenvolvimento do **MagicFridgeAI**, buscando consolidar conceitos de Java, programação reativa, APIs REST e integração com serviços externos.

Além de aplicar tecnologias já estudadas, o FocusLab AI tem como propósito explorar novos conceitos relacionados à persistência de dados, arquitetura de software, testes automatizados e boas práticas de desenvolvimento.

## 🚀 Objetivo do projeto

Desenvolver uma aplicação capaz de auxiliar estudantes na organização de suas rotinas de aprendizado, permitindo o gerenciamento de matérias, o acompanhamento do desempenho e a geração de questões com Inteligência Artificial.

O desenvolvimento será realizado de maneira progressiva, priorizando a compreensão dos conceitos e a implementação prática de cada funcionalidade.

## ⚙️ Tecnologias planejadas

- **Java**: linguagem principal
- **Spring Boot**: desenvolvimento da aplicação
- **Spring WebFlux**: construção de APIs reativas
- **Spring WebClient**: comunicação com serviços externos
- **Google Gemini API**: geração de conteúdo com IA
- **PostgreSQL**: banco de dados relacional
- **Spring Data R2DBC**: persistência reativa
- **Maven**: gerenciamento de dependências
- **Git e GitHub**: versionamento do código
- **JUnit e Mockito**: testes automatizados

As tecnologias serão incorporadas gradualmente conforme a evolução do projeto.

## 📌 Funcionalidades planejadas

### 1. Gerenciamento de matérias
- Cadastrar matérias de estudo
- Listar matérias cadastradas
- Atualizar informações
- Excluir matérias

### 2. Organização dos estudos
- Cadastrar tópicos de estudo
- Associar tópicos às matérias
- Registrar sessões de estudo
- Acompanhar conteúdos estudados

### 3. Simulados com Inteligência Artificial
- Gerar questões utilizando a API Gemini
- Personalizar questões conforme a matéria e o tópico
- Organizar perguntas e alternativas
- Disponibilizar respostas para avaliação

### 4. Acompanhamento de desempenho
- Registrar resultados dos simulados
- Calcular o percentual de acertos
- Consultar o histórico de desempenho
- Identificar conteúdos que precisam de revisão

## 🏗️ Arquitetura planejada

O projeto seguirá uma organização em camadas, separando as responsabilidades da aplicação.

- **Controller:** recebimento e tratamento das requisições HTTP
- **Service:** implementação das regras de negócio
- **Repository:** acesso e persistência dos dados
- **DTO:** transferência de dados entre as camadas
- **Config:** configurações da aplicação
- **Integration:** comunicação com a API de Inteligência Artificial
- **Exception:** tratamento centralizado de erros

A estrutura poderá ser ajustada conforme novas necessidades surgirem.
